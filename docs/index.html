edilint checks X12, HL7v2, EDIFACT, delimited, and fixed-width files for envelope defects and file hygiene problems. Each rule below explains what it catches, how to repair it, and when to adjust the check.

go install github.com/crb2nu/edilint/cmd/edilint@latest
edilint your-file.x12

The CLI runs locally with no network calls or telemetry. A clean file produces no output. This reference describes the current main branch; older releases may contain fewer rules. See the scope and limits.
