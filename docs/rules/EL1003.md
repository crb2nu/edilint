# EL1003 — charset.nonprintable

| Class | Severity | Applies to |
|---|---|---|
| charset | error | `all` |

Control character in record content that is not a declared separator. Tabs are reported as warnings.

## What it catches

C0 and C1 control characters inside record content, excluding the separators and terminators the file has declared. These arrive from copy-and-paste out of a terminal or from a field that captured a form feed. Tabs are graded a warning because they are common in hand-maintained extracts and rarely break a reader.

## Example

`eligibility.psv`:

```text
HDR|NORTHGATE HEALTH|20260115|ELIG
DTL|NGH900000001|RIVERA\x07|DANA|19840322|F|PPO-GOLD|20260101|20261231
```

The escape sequences above stand for the bytes the file holds literally.

`edilint eligibility.psv` reports:

```text
eligibility.psv:2:24: error: [EL1003 charset.nonprintable] non-printable control character BEL (U+0007) in record content; it is invisible in review and breaks field boundaries downstream (record 2, type DTL) https://crb2nu.github.io/edilint/rules/EL1003.html
```

## How to fix

Strip the control character from the source record. If it is meaningful — a tab inside a free-text note, say — escape it the way the receiver's specification requires instead of passing the raw byte.

## When to suppress

When the receiver's specification allows a specific control character in a specific field and the sending system depends on it. Suppress by rule for the affected file, not globally.

Suppress the rule for a run with `edilint --disable EL1003`, or for a repository by listing it under `disable:` in `.edilint.yml`.
