# EL7006 — edifact.control-reference

| Class | Severity | Applies to |
|---|---|---|
| edifact | error | `edifact` |

Header and trailer control references differ (UNB-5/UNZ-2, UNG-5/UNE-2, UNH-1/UNT-2), or a header's reference is empty.

## What it catches

A control reference that differs between a header and its trailer — UNB-5 against UNZ-2, UNG-5 against UNE-2, UNH-1 against UNT-2 — or a header whose reference is empty. The pair is how a receiver matches a trailer to its header and how both sides trace the interchange afterwards.

## Example

`order.edi`:

```text
UNA:+.? '
UNB+UNOA:4+NORTHGATEHEALTH+VALEMEDGROUP+260115:1430+NG260002'
UNH+NG0001+ORDERS:D:96A:UN'
BGM+220+NG77001+9'
UNT+3+NG0001'
UNZ+1+NG260099'
```

`edilint order.edi` reports:

```text
order.edi:6: error: [EL7006 edifact.control-reference] UNB-5 is "NG260002" but the matching UNZ-2 is "NG260099"; header and trailer control references must match (record 5, type UNZ)
```

## How to fix

Copy the header's reference into the trailer, taking the value from whichever the sending system considers authoritative.

## When to suppress

There is no safe case.

Suppress the rule for a run with `edilint --disable EL7006`, or for a repository by listing it under `disable:` in `.edilint.yml`.
