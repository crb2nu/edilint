# EL3008 — envelope.interchange-count

| Class | Severity | Applies to |
|---|---|---|
| envelope | error | `x12` |

IEA01 does not match the recounted functional groups in the interchange.

Trading partners report this defect with:

| Acknowledgment | Element | Code | Meaning |
|---|---|---|---|
| TA1 | `TA105` | `021` | invalid number of included groups value |

## What it catches

An IEA01 that disagrees with the number of GS segments in the interchange. As with the group count, it usually means a group was added or removed after the trailer was written.

## Example

`example.x12`:

```text
ISA*00*          *00*          *ZZ*NORTHGATEHEALTH*ZZ*VALEMEDGROUP   *260115*1430*^*00501*000000001*0*P*:~
GS*HP*NORTHGATEHEALTH*VALEMEDGROUP*20260115*1430*1*X*005010X221A1~
ST*835*0001~
BPR*I*4250.75*C*ACH*CCP~
SE*3*0001~
GE*1*1~
IEA*3*000000001~
```

`edilint example.x12` reports:

```text
example.x12:7: error: [EL3008 envelope.interchange-count] IEA01 declares 3 functional group(s) (GS) but the file contains 1 (record 7, segment IEA)
```

## How to fix

Recount the functional groups and write that number into IEA01. `edilint fix --write` rewrites it to the recounted value.

## When to suppress

There is no safe case.

Suppress the rule for a run with `edilint --disable EL3008`, or for a repository by listing it under `disable:` in `.edilint.yml`.
