terminator / error

EL2001

terminator.mixed

Applies to: hl7v2, delimited, fixed, text

What it catches and why it matters

File mixes CRLF, LF and CR line endings.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

HDR|EXAMPLE\r\nDTL|1\nTRL|1\r\n

How to fix it

Choose the receiver's required record terminator and export it consistently. edilint fix normalizes to the dominant observed style; review the diff before writing.

False positives and limits

A receiver may tolerate mixed endings, but other tools may not. The majority style is not proof of the intended style, especially for short files.

Acknowledgments and suppression

No X12 acknowledgment code names this defect; it is caught by the parser or the hygiene layer before an acknowledgment is produced.
Suppress the rule with --disable EL2001, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
