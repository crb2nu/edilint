EL4001

counts.mismatch

Applies to: all (requires --count-rule)

What it catches and why it matters

A declared record count does not match the recounted total.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

With --count-rule TRL:2:DTL:
DTL|EXAMPLE
TRL|2
(one DTL record, declared as two)

How to fix it

Verify the count rule's declaring field, counted record types, and scope. Then correct the exporter or declared total to match the intended records.

False positives and limits

A wrong count-rule expression can count a different population than the sender intended. Explicitly define whether headers, trailers, and other record types belong in the total.

Acknowledgments and suppression

No direct acknowledgment code is mapped for this rule.
Suppress the rule with --disable EL4001, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
