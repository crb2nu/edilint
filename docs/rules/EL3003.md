# EL3003 — envelope.unclosed

| Class | Severity | Applies to |
|---|---|---|
| envelope | error | `x12` |

ISA, GS or ST has no matching IEA, GE or SE.

Trading partners report this defect with:

| Acknowledgment | Element | Code | Meaning |
|---|---|---|---|
| TA1 | `TA105` | `023` | premature end of file, for an ISA with no IEA |
| 999 | `AK905` | `3` | functional group trailer missing |
| 999 | `IK502` | `2` | transaction set trailer missing |

## What it catches

A header with no matching trailer: ISA without IEA, GS without GE, ST without SE. A truncated transfer produces this, and so does a generator that fails partway through writing a transaction set and still ships what it wrote.

## Example

`example.x12`:

```text
ISA*00*          *00*          *ZZ*NORTHGATEHEALTH*ZZ*VALEMEDGROUP   *260115*1430*^*00501*000000001*0*P*:~
GS*HP*NORTHGATEHEALTH*VALEMEDGROUP*20260115*1430*1*X*005010X221A1~
ST*835*0001~
BPR*I*4250.75*C*ACH*CCP~
```

`edilint example.x12` reports:

```text
example.x12:1: error: [EL3003 envelope.unclosed] ISA is never closed by a matching IEA (record 1, segment ISA)
```

## How to fix

Resend the file. A missing trailer means the transaction set is incomplete, and writing the trailer by hand ships a file whose contents do not match what the sender intended.

## When to suppress

There is no safe case; the finding says the interchange is unfinished.

Suppress the rule for a run with `edilint --disable EL3003`, or for a repository by listing it under `disable:` in `.edilint.yml`.
