# EL4001 — counts.mismatch

| Class | Severity | Applies to |
|---|---|---|
| counts | error | `all (requires --count-rule)` |

A declared record count does not match the recounted total.

## What it catches

A declared record count does not match the recounted total.

## Example

This input is a minimal illustration of the defect:

```text
HDR|value
# counts.mismatch
```

The CLI reports:

```text
example.edi: error: [EL4001 counts.mismatch] A declared record count does not match the recounted total.
```

## How to fix

Correct the declaring field or record shape so it agrees with the records actually present in the file.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
