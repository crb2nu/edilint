# EL1007 — charset.x12-basic

| Class | Severity | Applies to |
|---|---|---|
| charset | warning | `x12 (requires --charset basic)` |

Character outside the X12 basic character set but inside the extended set. Off by default; the default profile is extended.

## What it catches

Character outside the X12 basic character set but inside the extended set. Off by default; the default profile is extended.

## Example

This input is a minimal illustration of the defect:

```text
ISA*...~
# charset.x12-basic
```

The CLI reports:

```text
example.edi: warning: [EL1007 charset.x12-basic] Character outside the X12 basic character set but inside the extended set. Off by default; the default profile is extended.
```

## How to fix

Remove or replace the reported byte or character, then save the file in the character set required by the receiver.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
