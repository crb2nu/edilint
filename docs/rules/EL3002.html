EL3002

envelope.nesting

Applies to: x12

What it catches and why it matters

GS appears outside an ISA, or ST outside a GS.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

ISA*...~ST*835*0001~  (ST occurs before any GS)

How to fix it

Restore the missing parent envelope or correct segment ordering in the exporter. Ensure GS is inside ISA and ST is inside GS.

False positives and limits

An extracted transaction fragment lacks its parent envelopes. Lint the complete interchange when checking envelope integrity.

Acknowledgments and suppression

Related acknowledgment codes (apply only to the described defect):
  TA1 code 024 (TA105): invalid interchange content, for a GS outside any ISA
  999 code 18 (IK502): transaction set not in a functional group, for an ST outside any GS
Suppress the rule with --disable EL3002, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
Reference: https://crb2nu.github.io/edilint/rules/EL3002.html
