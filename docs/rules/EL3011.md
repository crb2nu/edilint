# EL3011 — envelope.missing-control-id

| Class | Severity | Applies to |
|---|---|---|
| envelope | error | `x12` |

ISA13, GS06 or ST02 control number is empty.

Trading partners report this defect with:

| Acknowledgment | Element | Code | Meaning |
|---|---|---|---|
| TA1 | `TA105` | `018` | invalid interchange control number value, only when this finding reports an empty ISA13 |

## What it catches

An ISA13, GS06 or ST02 that is blank. The interchange, group and transaction set control numbers are what a receiver acknowledges and what both sides use to trace a file after the fact; an empty one leaves that envelope unidentifiable. A blank header closed by a blank trailer compares equal, and blank values are not checked for duplicates, so this rule is the only finding such an envelope gets.

## Example

`example.x12`:

```text
ISA*00*          *00*          *ZZ*NORTHGATEHEALTH*ZZ*VALEMEDGROUP   *260115*1430*^*00501*         *0*P*:~
GS*HP*NORTHGATEHEALTH*VALEMEDGROUP*20260115*1430*1*X*005010X221A1~
ST*835*0001~
BPR*I*4250.75*C*ACH*CCP~
SE*3*0001~
GE*1*1~
IEA*1*         ~
```

`edilint example.x12` reports:

```text
example.x12:1: error: [EL3011 envelope.missing-control-id] ISA13 interchange control number is empty (record 1, segment ISA) https://crb2nu.github.io/edilint/rules/EL3011.html
```

## How to fix

Populate ISA13, GS06 and ST02 from the sender's control counters and copy each value into its trailer: IEA02, GE02 and SE02. ISA13 is fixed-width, so its value is normally zero-padded to nine characters.

## When to suppress

There is no safe case.

Suppress the rule for a run with `edilint --disable EL3011`, or for a repository by listing it under `disable:` in `.edilint.yml`.
