# EL3005 — envelope.control-number

| Class | Severity | Applies to |
|---|---|---|
| envelope | error | `x12` |

Header and trailer control numbers differ (ISA13/IEA02, GS06/GE02, ST02/SE02). A leading-zero-only difference is reported as a warning.

## What it catches

Header and trailer control numbers differ (ISA13/IEA02, GS06/GE02, ST02/SE02). A leading-zero-only difference is reported as a warning.

## Example

This input is a minimal illustration of the defect:

```text
ISA*...~
# envelope.control-number
```

The CLI reports:

```text
example.edi: error: [EL3005 envelope.control-number] Header and trailer control numbers differ (ISA13/IEA02, GS06/GE02, ST02/SE02). A leading-zero-only difference is reported as a warning.
```

## How to fix

Regenerate the envelope from the payload, preserving its nesting and recalculating trailer values and control references.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
