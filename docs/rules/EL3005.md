# EL3005 — envelope.control-number

| Class | Severity | Applies to |
|---|---|---|
| envelope | error | `x12` |

Header and trailer control numbers differ (ISA13/IEA02, GS06/GE02, ST02/SE02). A leading-zero-only difference is reported as a warning.

Trading partners report this defect with:

| Acknowledgment | Element | Code | Meaning |
|---|---|---|---|
| TA1 | `TA105` | `001` | interchange control numbers in the header and trailer do not match |
| 999 | `AK905` | `4` | group control numbers in the header and trailer do not agree |
| 999 | `IK502` | `3` | transaction set control numbers in the header and trailer do not match |

## What it catches

A control number that differs between a header and its trailer: ISA13 against IEA02, GS06 against GE02, ST02 against SE02. The pair is how a receiver matches a trailer to its header when interchanges are being reassembled. A difference of leading zeros alone is reported as a warning, because the values compare equal numerically and many partners accept it.

## Example

`example.x12`:

```text
ISA*00*          *00*          *ZZ*NORTHGATEHEALTH*ZZ*VALEMEDGROUP   *260115*1430*^*00501*000000001*0*P*:~
GS*HP*NORTHGATEHEALTH*VALEMEDGROUP*20260115*1430*1*X*005010X221A1~
ST*835*0001~
BPR*I*4250.75*C*ACH*CCP~
SE*3*0001~
GE*1*1~
IEA*1*000000002~
```

`edilint example.x12` reports:

```text
example.x12:7: error: [EL3005 envelope.control-number] ISA13 is "000000001" but the matching IEA02 is "000000002"; header and trailer control numbers must match (record 7, segment IEA) https://crb2nu.github.io/edilint/rules/EL3005.html
```

## How to fix

Copy the header's control number into the trailer. Which of the two is correct depends on what the sender recorded, so take the value from whichever the sending system considers authoritative.

## When to suppress

When a partner is known to zero-pad trailers differently and the difference is leading zeros only. Downgrade that case rather than disabling the rule, so a genuine mismatch still reports.

Suppress the rule for a run with `edilint --disable EL3005`, or for a repository by listing it under `disable:` in `.edilint.yml`.
