# EL2006 — terminator.edifact-segment

| Class | Severity | Applies to |
|---|---|---|
| terminator | error | `edifact` |

Segment is not closed by the segment terminator in force, which in practice means the file was truncated mid-segment.

## What it catches

Segment is not closed by the segment terminator in force, which in practice means the file was truncated mid-segment.

## Example

This input is a minimal illustration of the defect:

```text
UNB+...'
# terminator.edifact-segment
```

The CLI reports:

```text
example.edi: error: [EL2006 terminator.edifact-segment] Segment is not closed by the segment terminator in force, which in practice means the file was truncated mid-segment.
```

## How to fix

Rewrite the affected record or segment boundary using the separator and terminator declared for the file.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
