EL4004

counts.no-declaring-record

Applies to: all (requires --count-rule)

What it catches and why it matters

No record matched the count rule's declaring prefix, so nothing was verified.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

With --count-rule TRL:2:DTL, the file contains DTL records but no TRL record.

How to fix it

Restore the declaring record if the feed requires it. Otherwise remove the count assertion or use the actual declaring record type.

False positives and limits

A count rule shared across feeds can name a trailer that some feeds do not have. This warning means that the assertion was not checked, not that a total was proved incorrect.

Acknowledgments and suppression

No direct acknowledgment code is mapped for this rule.
Suppress the rule with --disable EL4004, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
