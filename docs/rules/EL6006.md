# EL6006 — hl7batch.stray-message

| Class | Severity | Applies to |
|---|---|---|
| hl7batch | warning | `hl7v2` |

MSH appears outside any open batch in a file that uses batch envelopes, so batch-aware readers will not process it. Files with no BHS at all are not checked; bare message streams are valid without an envelope.

## What it catches

MSH appears outside any open batch in a file that uses batch envelopes, so batch-aware readers will not process it. Files with no BHS at all are not checked; bare message streams are valid without an envelope.

## Example

This input is a minimal illustration of the defect:

```text
MSH|^~\&|...
# hl7batch.stray-message
```

The CLI reports:

```text
example.edi: warning: [EL6006 hl7batch.stray-message] MSH appears outside any open batch in a file that uses batch envelopes, so batch-aware readers will not process it. Files with no BHS at all are not checked; bare message streams are valid without an envelope.
```

## How to fix

Regenerate the envelope from the payload, preserving its nesting and recalculating trailer values and control references.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
