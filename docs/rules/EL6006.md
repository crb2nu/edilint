# EL6006 — hl7batch.stray-message

| Class | Severity | Applies to |
|---|---|---|
| hl7batch | warning | `hl7v2` |

MSH appears outside any open batch in a file that uses batch envelopes, so batch-aware readers will not process it. Files with no BHS at all are not checked; bare message streams are valid without an envelope.

## What it catches

An MSH outside any open batch in a file that uses batch envelopes. Batch-aware readers process what is inside the envelope, so a stray message is silently skipped. Files with no BHS at all are not checked — a bare message stream is valid without an envelope.

## Example

`batch.hl7`:

```text
FHS|^~\&|NORTHGATEHEALTH|NGCLINIC|VALEMEDGROUP|VMOFFICE|20260115143000|||NGFILE0001
BHS|^~\&|NORTHGATEHEALTH|NGCLINIC|VALEMEDGROUP|VMOFFICE|20260115143000|||NGBATCH0001
MSH|^~\&|NORTHGATEHEALTH|NGCLINIC|VALEMEDGROUP|VMOFFICE|20260115143000||ADT^A08|NGMSG0001|P|2.5.1
PID|1||NGH900000001^^^NORTHGATE^MR||RIVERA^DANA
BTS|1
MSH|^~\&|NORTHGATEHEALTH|NGCLINIC|VALEMEDGROUP|VMOFFICE|20260115143000||ADT^A08|NGMSG0001|P|2.5.1
PID|1||NGH900000001^^^NORTHGATE^MR||RIVERA^DANA
FTS|1
```

`edilint batch.hl7` reports:

```text
batch.hl7:6: warning: [EL6006 hl7batch.stray-message] MSH appears outside any batch in a file that uses batch envelopes; batch-aware readers process only the messages between BHS and BTS (record 6, segment MSH) https://crb2nu.github.io/edilint/rules/EL6006.html
```

## How to fix

Move the message inside the batch it belongs to and update BTS-1, or give it its own BHS and BTS. Which applies depends on whether the message was meant to be part of that batch.

## When to suppress

When a partner's reader is known to process messages outside the envelope as well. It is a warning for that reason.

Suppress the rule for a run with `edilint --disable EL6006`, or for a repository by listing it under `disable:` in `.edilint.yml`.
