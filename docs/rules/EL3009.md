# EL3009 — envelope.duplicate-control-number

| Class | Severity | Applies to |
|---|---|---|
| envelope | error | `x12` |

Duplicate ISA13 within the file or across the files in one run, duplicate GS06 within an interchange, or duplicate ST02 within a functional group.

Trading partners report this defect with:

| Acknowledgment | Element | Code | Meaning |
|---|---|---|---|
| TA1 | `TA105` | `025` | duplicate interchange control number |
| 999 | `AK905` | `19` | functional group control number not unique within the interchange |
| 999 | `IK502` | `23` | transaction set control number not unique within the functional group |

## What it catches

A control number reused where it must be unique: ISA13 within a file or across the files of one run, GS06 within an interchange, ST02 within a functional group. Receivers deduplicate on these, so a reused number is how a real claim silently fails to post.

## Example

`example.x12`:

```text
ISA*00*          *00*          *ZZ*NORTHGATEHEALTH*ZZ*VALEMEDGROUP   *260115*1430*^*00501*000000001*0*P*:~
GS*HP*NORTHGATEHEALTH*VALEMEDGROUP*20260115*1430*1*X*005010X221A1~
ST*835*0001~
BPR*I*4250.75*C*ACH*CCP~
SE*3*0001~
ST*835*0001~
BPR*I*4250.75*C*ACH*CCP~
SE*3*0001~
GE*2*1~
IEA*1*000000001~
```

`edilint example.x12` reports:

```text
example.x12:6: error: [EL3009 envelope.duplicate-control-number] ST02 control number "0001" is already used by record 3 in this functional group; control numbers must be unique within their scope (record 6, segment ST) https://crb2nu.github.io/edilint/rules/EL3009.html
```

## How to fix

Assign each interchange, group and transaction set its own control number from the sender's sequence. A repeated ISA13 across a run usually means a counter was not persisted between invocations.

## When to suppress

There is no safe case. A duplicate is either a resend the receiver will discard or a distinct transaction the receiver will discard, and both are wrong.

Suppress the rule for a run with `edilint --disable EL3009`, or for a repository by listing it under `disable:` in `.edilint.yml`.
