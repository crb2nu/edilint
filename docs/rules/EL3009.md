# EL3009 — envelope.duplicate-control-number

| Class | Severity | Applies to |
|---|---|---|
| envelope | error | `x12` |

Duplicate ISA13 within the file or across the files in one run, duplicate GS06 within an interchange, or duplicate ST02 within a functional group.

## What it catches

Duplicate ISA13 within the file or across the files in one run, duplicate GS06 within an interchange, or duplicate ST02 within a functional group.

## Example

This input is a minimal illustration of the defect:

```text
ISA*...~
# envelope.duplicate-control-number
```

The CLI reports:

```text
example.edi: error: [EL3009 envelope.duplicate-control-number] Duplicate ISA13 within the file or across the files in one run, duplicate GS06 within an interchange, or duplicate ST02 within a functional group.
```

## How to fix

Regenerate the envelope from the payload, preserving its nesting and recalculating trailer values and control references.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
