EL7007

edifact.service-string

Applies to: edifact

What it catches and why it matters

UNA is not the fixed nine characters, its service characters collide or are alphanumeric, or its decimal mark is not a period or a comma.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

UNA++.? '  (component and element separators both use +)

How to fix it

Emit a nine-character UNA with distinct permitted service characters and a period or comma decimal mark. Ensure the payload uses those declarations.

False positives and limits

Truncated or incorrectly decoded UNA bytes can create secondary separator errors. Verify the original export before rewriting the service string.

Acknowledgments and suppression

No X12 acknowledgment code names this defect; it is caught by the parser or the hygiene layer before an acknowledgment is produced.
Suppress the rule with --disable EL7007, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
