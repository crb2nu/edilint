# EL7001 — edifact.unclosed

| Class | Severity | Applies to |
|---|---|---|
| edifact | error | `edifact` |

UNB, UNG or UNH is never closed by a matching UNZ, UNE or UNT.

Trading partners report this defect with:

| Acknowledgment | Element | Code | Meaning |
|---|---|---|---|
| CONTRL | `UCI.0085` | `13` | UNZ is missing |
| CONTRL | `UCF.0085` | `13` | UNE is missing |
| CONTRL | `UCM.0085` | `13` | UNT is missing |

## What it catches

A UNB, UNG or UNH that is never closed by its UNZ, UNE or UNT. A truncated transfer is the usual cause, and because EDIFACT is not line-oriented the truncation can fall anywhere.

## Example

`order.edi`:

```text
UNA:+.? '
UNB+UNOA:4+NORTHGATEHEALTH+VALEMEDGROUP+260115:1430+NG260002'
UNH+NG0001+ORDERS:D:96A:UN'
BGM+220+NG77001+9'
```

`edilint order.edi` reports:

```text
order.edi:2: error: [EL7001 edifact.unclosed] UNB is never closed by a matching UNZ (record 1, type UNB) https://crb2nu.github.io/edilint/rules/EL7001.html
```

## How to fix

Resend the file. A missing trailer means content is absent, so writing the trailer would ship an interchange that does not match what the sender assembled.

## When to suppress

There is no safe case; the interchange is incomplete.

Suppress the rule for a run with `edilint --disable EL7001`, or for a repository by listing it under `disable:` in `.edilint.yml`.
