charset / warning

EL1006

charset.nonascii

Applies to: all

What it catches and why it matters

Non-ASCII character that is not a known lookalike.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

N1*PR*CAFÉ~  (É is non-ASCII)

How to fix it

Confirm the feed's allowed character set. If it requires ASCII, correct the export using an agreed transliteration policy rather than silently dropping characters.

False positives and limits

Unicode names and free text may be intentional. This is a warning for review; an agreed Unicode feed can disable or downgrade it.

Acknowledgments and suppression

No direct acknowledgment code is mapped for this rule.
Suppress the rule with --disable EL1006, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
