# EL6005 — hl7batch.separator

| Class | Severity | Applies to |
|---|---|---|
| hl7batch | error | `hl7v2` |

FHS, BHS and MSH headers disagree on the field separator or the encoding characters, or a header's encoding characters are malformed. Split-and-merge tooling reads every message with the first header's separators, so a disagreeing message is misparsed.

## What it catches

FHS, BHS and MSH headers disagree on the field separator or the encoding characters, or a header's encoding characters are malformed. Split-and-merge tooling reads every message with the first header's separators, so a disagreeing message is misparsed.

## Example

This input is a minimal illustration of the defect:

```text
MSH|^~\&|...
# hl7batch.separator
```

The CLI reports:

```text
example.edi: error: [EL6005 hl7batch.separator] FHS, BHS and MSH headers disagree on the field separator or the encoding characters, or a header's encoding characters are malformed. Split-and-merge tooling reads every message with the first header's separators, so a disagreeing message is misparsed.
```

## How to fix

Regenerate the envelope from the payload, preserving its nesting and recalculating trailer values and control references.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
