# EL2004 — terminator.x12-padding

| Class | Severity | Applies to |
|---|---|---|
| terminator | warning | `x12` |

Whitespace between segment terminators is applied inconsistently.

## What it catches

Whitespace between segment terminators is applied inconsistently.

## Example

This input is a minimal illustration of the defect:

```text
ISA*...~
# terminator.x12-padding
```

The CLI reports:

```text
example.edi: warning: [EL2004 terminator.x12-padding] Whitespace between segment terminators is applied inconsistently.
```

## How to fix

Rewrite the affected record or segment boundary using the separator and terminator declared for the file.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
