EL4002

counts.unparsable

Applies to: all (requires --count-rule)

What it catches and why it matters

The field a count rule points at is not an integer.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

With --count-rule TRL:2:DTL: TRL|MANY

How to fix it

Write an integer in the declared count field, or correct the count rule if it points at a label rather than the count.

False positives and limits

The configured field index or delimiter may be wrong. Check how the record was split before replacing the value.

Acknowledgments and suppression

No direct acknowledgment code is mapped for this rule.
Suppress the rule with --disable EL4002, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
