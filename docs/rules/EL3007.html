EL3007

envelope.group-count

Applies to: x12

What it catches and why it matters

GE01 does not match the recounted transaction sets in the group.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

A GS contains one ST/SE transaction set but ends with GE*2*1~.

How to fix it

Set GE01 to the number of transaction sets in that group. Preview edilint fix after checking that all intended transactions are present.

False positives and limits

Broken transaction nesting can distort the recount. Repair structural findings before trusting a replacement count.

Acknowledgments and suppression

A trading partner's front end reports this defect as:
  999 code 5 (AK905): number of included transaction sets does not match the actual count
Suppress the rule with --disable EL3007, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
