# EL6002 — hl7batch.unopened

| Class | Severity | Applies to |
|---|---|---|
| hl7batch | error | `hl7v2` |

FTS or BTS appears without its matching FHS or BHS header.

## What it catches

An FTS or BTS trailer with no matching header. Two files concatenated, or a batch split at the wrong boundary, both produce a trailer that closes nothing.

## Example

`batch.hl7`:

```text
MSH|^~\&|NORTHGATEHEALTH|NGCLINIC|VALEMEDGROUP|VMOFFICE|20260115143000||ADT^A08|NGMSG0001|P|2.5.1
PID|1||NGH900000001^^^NORTHGATE^MR||RIVERA^DANA
BTS|1
```

`edilint batch.hl7` reports:

```text
batch.hl7:3: error: [EL6002 hl7batch.unopened] BTS appears without a preceding BHS (record 3, segment BTS) https://crb2nu.github.io/edilint/rules/EL6002.html
```

## How to fix

Rejoin the file with its header, or split it so that each batch keeps its own header and trailer together.

## When to suppress

There is no safe case.

Suppress the rule for a run with `edilint --disable EL6002`, or for a repository by listing it under `disable:` in `.edilint.yml`.
