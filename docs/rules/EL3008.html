EL3008

envelope.interchange-count

Applies to: x12

What it catches and why it matters

IEA01 does not match the recounted functional groups in the interchange.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

An ISA contains one GS/GE group but ends with IEA*2*000000001~.

How to fix it

Set IEA01 to the number of functional groups in that interchange. Preview edilint fix after confirming the export is complete.

False positives and limits

Malformed or missing group headers can affect the observed total. A corrected count alone does not establish that the file contains every intended group.

Acknowledgments and suppression

Related acknowledgment codes (apply only to the described defect):
  TA1 code 021 (TA105): invalid number of included groups value
Suppress the rule with --disable EL3008, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
