# EL7004 — edifact.group-count

| Class | Severity | Applies to |
|---|---|---|
| edifact | error | `edifact` |

UNE-1 does not match the recounted messages in the functional group.

## What it catches

A UNE-1 that disagrees with the number of UNH messages in the functional group. Groups are optional in EDIFACT, so this only applies to interchanges that use UNG.

## Example

`order.edi`:

```text
UNA:+.? '
UNB+UNOA:4+NORTHGATEHEALTH+VALEMEDGROUP+260115:1430+NG260002'
UNG+ORDERS+NORTHGATEHEALTH+VALEMEDGROUP+260115:1430+1+UN+D:96A'
UNH+NG0001+ORDERS:D:96A:UN'
BGM+220+NG77001+9'
UNT+3+NG0001'
UNE+4+1'
UNZ+1+NG260002'
```

`edilint order.edi` reports:

```text
order.edi:7: error: [EL7004 edifact.group-count] UNE-1 declares 4 message(s) (UNH) but the group contains 1 (record 6, type UNE)
```

## How to fix

Recount the messages in the group and write that number into UNE-1.

## When to suppress

There is no safe case.

Suppress the rule for a run with `edilint --disable EL7004`, or for a repository by listing it under `disable:` in `.edilint.yml`.
