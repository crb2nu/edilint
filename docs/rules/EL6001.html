EL6001

hl7batch.unclosed

Applies to: hl7v2

What it catches and why it matters

FHS or BHS is never closed by a matching FTS or BTS, so the batch envelope is incomplete.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

BHS|^~\&
MSH|^~\&|EXAMPLE
  (no BTS follows)

How to fix it

Restore the complete batch or file envelope, including BTS for BHS and FTS for FHS. Confirm completeness before recounting trailers.

False positives and limits

Bare MSH message streams are valid without batch headers. This pairing rule applies when envelope segments are present; partial captures may omit the closing segment.

Acknowledgments and suppression

No X12 acknowledgment code names this defect; it is caught by the parser or the hygiene layer before an acknowledgment is produced.
Suppress the rule with --disable EL6001, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
