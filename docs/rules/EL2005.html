EL2005

terminator.x12-separator

Applies to: x12

What it catches and why it matters

Declared separators collide with each other or are alphanumeric.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

ISA declares * as both the element separator and the component separator.

How to fix it

Regenerate the interchange with distinct, non-alphanumeric separators and ensure the body uses those declarations. Editing only ISA can change how existing data is parsed.

False positives and limits

A malformed or incorrectly padded ISA can shift separator positions and cause this secondary finding. Correct the ISA structure first.

Acknowledgments and suppression

A trading partner's front end reports this defect as:
  TA1 code 026 (TA105): invalid data element separator
  TA1 code 027 (TA105): invalid component element separator
  TA1 code 032 (TA105): invalid repetition separator
  TA1 code 004 (TA105): the segment terminator is invalid
Suppress the rule with --disable EL2005, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
