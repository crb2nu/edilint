EL3011

envelope.missing-control-id

Applies to: x12

What it catches and why it matters

ISA13 interchange control number is empty.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

ISA13 is empty or contains only spaces.

How to fix it

Populate the interchange control number from the sender's control sequence and use the same value in IEA02.

False positives and limits

A shifted or short ISA can make the control field appear empty. Repair ISA length and separators before assigning a new control value.

Acknowledgments and suppression

A trading partner's front end reports this defect as:
  TA1 code 018 (TA105): invalid interchange control number value
Suppress the rule with --disable EL3011, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
