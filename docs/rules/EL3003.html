EL3003

envelope.unclosed

Applies to: x12

What it catches and why it matters

ISA, GS or ST has no matching IEA, GE or SE.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

ISA*...~GS*...~ST*835*0001~  (file ends before SE, GE, and IEA)

How to fix it

Recover the full export and restore matching trailers with correct counts and control numbers. Do not fabricate trailers if payload may have been truncated.

False positives and limits

A deliberate partial interchange or a missing segment terminator can look unclosed. Check file completeness and terminators first.

Acknowledgments and suppression

Related acknowledgment codes (apply only to the described defect):
  TA1 code 023 (TA105): premature end of file, for an ISA with no IEA
  999 code 3 (AK905): functional group trailer missing
  999 code 2 (IK502): transaction set trailer missing
Suppress the rule with --disable EL3003, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
Reference: https://crb2nu.github.io/edilint/rules/EL3003.html
