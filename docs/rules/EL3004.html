envelope / error

EL3004

envelope.unopened

Applies to: x12

What it catches and why it matters

IEA, GE or SE appears without its header.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

SE*2*0001~  (no preceding ST in the active group)

How to fix it

Restore the corresponding header or remove an unintended duplicate trailer at the source. Recheck nesting after repairing the file.

False positives and limits

A fragment starting in the middle of an interchange can contain a trailer without its header. Use the full interchange for this check.

Acknowledgments and suppression

A trading partner's front end reports this defect as:
  TA1 code 022 (TA105): invalid control structure
  999 code 2 (IK304): unexpected segment
Suppress the rule with --disable EL3004, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
Reference: https://crb2nu.github.io/edilint/rules/EL3004.html
