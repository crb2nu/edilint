EL3001

envelope.isa-length

Applies to: x12

What it catches and why it matters

ISA segment is not the fixed 106 characters, or is absent.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

ISA*00*~  (far shorter than the fixed ISA envelope header)

How to fix it

Regenerate ISA with the required fixed-width fields and separators. Do not trim its space-padded fields. Remove a leading BOM if one displaced the header.

False positives and limits

Forcing --type x12 on a non-X12 file also triggers this rule. Confirm format detection before repairing the input.

Acknowledgments and suppression

A trading partner's front end reports this defect as:
  TA1 code 022 (TA105): invalid control structure; a receiver that cannot read the ISA often cannot return a TA1 at all and drops the transmission
Suppress the rule with --disable EL3001, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
