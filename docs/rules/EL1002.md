# EL1002 — charset.invalid-utf8

| Class | Severity | Applies to |
|---|---|---|
| charset | error | `all` |

Byte sequence is not valid UTF-8.

## What it catches

Byte sequence is not valid UTF-8.

## Example

This input is a minimal illustration of the defect:

```text
HDR|value
# charset.invalid-utf8
```

The CLI reports:

```text
example.edi: error: [EL1002 charset.invalid-utf8] Byte sequence is not valid UTF-8.
```

## How to fix

Remove or replace the reported byte or character, then save the file in the character set required by the receiver.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
