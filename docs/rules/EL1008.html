EL1008

charset.x12-extended

Applies to: x12

What it catches and why it matters

Character outside the X12 extended character set, which in printable ASCII means the caret or the backtick. A caret is exempt when ISA11 declares it as the repetition separator.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

N1*PR*AC`ME~  (backtick in a data element)

How to fix it

Replace the unintended character at the source with the intended permitted value. Verify ISA separator declarations before editing characters used structurally.

False positives and limits

A caret is allowed when ISA11 declares it as the repetition separator. A partner-specific character agreement may differ from this profile; document that agreement before overriding the rule.

Acknowledgments and suppression

Related acknowledgment codes (apply only to the described defect):
  999 code 6 (IK403): invalid character in a data element
Suppress the rule with --disable EL1008, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
