charset / error

EL1003

charset.nonprintable

Applies to: all

What it catches and why it matters

Control character in record content that is not a declared separator. Tabs are reported as warnings.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

NTE*ADD*EXAMPLE\x00TEXT~

How to fix it

Remove the unintended control byte in the exporting system. Preserve declared field and record separators. Check whether tabs came from spreadsheet or copy-and-paste processing.

False positives and limits

Tabs in record content are warnings. A nonstandard feed may intentionally carry control bytes; suppress the rule only when the consumer explicitly accepts them. Declared separators are exempt.

Acknowledgments and suppression

No direct acknowledgment code is mapped for this rule.
Suppress the rule with --disable EL1003, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
