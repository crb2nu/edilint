# EL1008 — charset.x12-extended

| Class | Severity | Applies to |
|---|---|---|
| charset | error | `x12` |

Character outside the X12 extended character set, which in printable ASCII means the caret or the backtick. A caret is exempt when ISA11 declares it as the repetition separator.

## What it catches

Character outside the X12 extended character set, which in printable ASCII means the caret or the backtick. A caret is exempt when ISA11 declares it as the repetition separator.

## Example

This input is a minimal illustration of the defect:

```text
ISA*...~
# charset.x12-extended
```

The CLI reports:

```text
example.edi: error: [EL1008 charset.x12-extended] Character outside the X12 extended character set, which in printable ASCII means the caret or the backtick. A caret is exempt when ISA11 declares it as the repetition separator.
```

## How to fix

Remove or replace the reported byte or character, then save the file in the character set required by the receiver.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
