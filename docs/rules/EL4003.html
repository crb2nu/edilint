EL4003

counts.missing-field

Applies to: all (requires --count-rule)

What it catches and why it matters

The declaring record has fewer fields than the count rule reads.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

With --count-rule TRL:3:DTL: TRL|1  (field 3 is absent)

How to fix it

Supply the missing declaring field or correct the configured count-field index. Field indexes are 1-based, so the record type occupies field 1.

False positives and limits

An incorrect delimiter, record-type field, or count index can make a present field look missing. Verify the layout against the rule expression.

Acknowledgments and suppression

No direct acknowledgment code is mapped for this rule.
Suppress the rule with --disable EL4003, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
