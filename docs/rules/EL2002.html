edilint / rule reference

terminator / warning

EL2002

terminator.missing-final

Applies to: hl7v2, delimited, fixed, text

What it catches and why it matters

Last record has no terminator.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

HDR|EXAMPLE\nDTL|1  (end of file immediately after 1)

How to fix it

Append the agreed final record terminator. edilint fix can add it when the existing records establish a style.

False positives and limits

Some line-oriented formats permit an unterminated final record. This is a warning; suppress it if the consumer's contract permits that form.

Acknowledgments and suppression

No X12 acknowledgment code names this defect; it is caught by the parser or the hygiene layer before an acknowledgment is produced.
Suppress the rule with --disable EL2002, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
