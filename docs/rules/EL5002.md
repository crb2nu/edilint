# EL5002 — layout.padding

| Class | Severity | Applies to |
|---|---|---|
| layout | warning | `fixed (requires --layout)` |

A field's padding is unambiguously on the side opposite the one the layout declares.

## What it catches

A field's padding is unambiguously on the side opposite the one the layout declares.

## Example

This input is a minimal illustration of the defect:

```text
RECORD  # layout.padding
```

The CLI reports:

```text
example.edi: warning: [EL5002 layout.padding] A field's padding is unambiguously on the side opposite the one the layout declares.
```

## How to fix

Format the record from the declared layout, using each field's width, alignment, and padding.

## When to suppress

Suppress this rule only when the receiving system explicitly accepts the condition and changing the source data is not possible. Prefer a narrow rule suppression for the affected file; record the receiver requirement alongside it.
