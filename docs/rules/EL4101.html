EL4101

fields.count-outlier

Applies to: delimited, hl7v2 (warning)

What it catches and why it matters

A record carries a different number of fields from others of the same record type.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

DTL|A|1
DTL|B|2
DTL|C
(the last DTL has fewer fields)

How to fix it

Restore missing delimiters or fields, or remove an unintended delimiter in data. Compare records of the same type and verify the configured type field.

False positives and limits

Optional trailing fields and variable-length record types can be intentional. HL7v2 findings are warnings for this reason. Disable or downgrade this heuristic for known variable layouts.

Acknowledgments and suppression

No direct acknowledgment code is mapped for this rule.
Suppress the rule with --disable EL4101, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
