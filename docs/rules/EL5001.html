EL5001

layout.length

Applies to: fixed (requires --layout)

What it catches and why it matters

Record length does not match the sum of the layout's field widths.

Failing example

These synthetic fragments illustrate the defect; they are not complete interchange files. Backslash escapes name bytes such as \r (CR) and \n (LF).

A layout declares field widths 3 and 5, but the record contains only seven bytes.

How to fix it

Regenerate each record at the total width declared by its layout, padding each field as specified. Check that the supplied layout describes this feed version.

False positives and limits

A stale layout can report valid data. Widths are measured in bytes, so multibyte UTF-8 characters occupy more than one position. Confirm that the layout describes this feed before adding padding.

Acknowledgments and suppression

No direct acknowledgment code is mapped for this rule.
Suppress the rule with --disable EL5001, or list it under "disable" in .edilint.yml. To accept the occurrences a file already has without suppressing the rule, record them with --write-baseline and run with --baseline.
